# Fan-In Lab

Навчальний проєкт для дослідження патерна **Fan-In (мультиплексор)**.

## Мета

- зрозуміти принцип роботи fan-in;
- об'єднати кілька асинхронних потоків даних в один потік;
- зберегти порядок елементів у межах кожного джерела;
- обробляти помилки окремих входів без зупинки інших;
- перевірити коректне завершення після завершення всіх входів.

## Що таке fan-in

Fan-In — це патерн, за допомогою якого кілька незалежних асинхронних джерел даних об'єднуються в один потік.

Це корисно для:

- агрегації даних з кількох API або стрімів;
- обробки кількох одночасних джерел подій;
- збору результатів з декількох паралельних процесів;
- інтеграції даних без втрати реактивності;
- досягнення більш гнучкого сценарію обробки потоку.

## Як працює реалізація

У цьому проєкті fan-in реалізовано у функції `fanIn(inputs)` у файлі `src/fan-in.ts`.

Параметри:

- `inputs` — масив асинхронних iterable-потоків, які потрібно об'єднати в один.

Функція повертає асинхронний генератор, який:

- читає дані з кожного входу без блокування інших потоків;
- видає елементи в порядку, який визначається найшвидшим доступним джерелом;
- зберігає порядок всередині кожного окремого потоку;
- повертає результат у форматі `Result` з інформацією про джерело та помилку;
- після завершення всіх входів коректно завершує роботу.

### Основні сценарії

1. `кілька потоків працюють одночасно`  
   Відбувається міксування елементів з усіх джерел, без блокування більш повільних входів.

2. `порядок у межах одного потоку зберігається`  
   Для кожного джерела послідовність елементів не порушується.

3. `один потік падає з помилкою`  
   Помилка фіксується як результат `ok: false`, але інші входи продовжують працювати.

4. `всі входи завершились`  
   Генератор завершується після того, як всі потоки закрилися або померли.

## Приклад

```typescript
const merged = fanIn<string>([
  source(["a1", "a2", "a3"], 20),
  source(["b1", "b2"], 10),
]);

for await (const item of merged) {
  if (item.ok) {
    console.log(item.source, item.value);
  } else {
    console.error(item.source, item.error);
  }
}
```

У цьому прикладі дані з різних входів зливаються в один потік, при цьому кожен потік зберігає свій внутрішній порядок.

## Підготовка

1. Завантажте репозиторій та перейдіть у папку проєкту:

```bash
git clone https://github.com/marchuk-b/cloud-technologies-and-big-data.git
cd lab6/fan-in
```

2. Встановіть залежності:

```bash
npm install
```

## Запуск demo

Для запуску демонстраційного прикладу використовуйте:

```bash
npm run dev
```

Демонстраційний приклад знаходиться у файлі `src/index.ts`.

## Тести

Тести перевіряють:

- злиття кількох потоків в один;
- збереження порядку елементів у межах кожного stream;

- завершення після обробки всіх входів;
