# Timeout Lab

Навчальний проєкт для дослідження патерна **Timeout**.

## Мета

- зрозуміти принцип роботи timeout;
- обмежити час виконання асинхронної операції;
- вчасно завершувати виконання, якщо операція "залипає";
- реалізувати обгортку для перевірки тайм-ауту;
- протестувати власний timeout-обробник.

## Що таке timeout

Timeout — це механізм, який обмежує максимальний час виконання асинхронної операції.

Це корисно для:

- запитів до API;
- довгих базових операцій;
- очікування відповіді від сервера;
- обробки "завислих" задач;
- запобігання зависанням застосунку.

## Як працює реалізація

У цьому проєкті timeout реалізовано у класі `Timeouter` у файлі `src/timeouter.ts`.

Параметри:

- `timeoutMs` — максимально допустима тривалість виконання в мілісекундах.

Метод `withTimeout(fn)` приймає асинхронну функцію та повертає обіцянку, яка:

- резолвиться зі значенням, якщо операція завершилась до тайм-ауту;
- реджектиться з помилкою `Operation timed out`, якщо операція не завершилась вчасно;
- пробрасыє оригінальну помилку операції, якщо вона завершилась з помилкою до тайм-ауту.

### Основні сценарії

1. `операція завершилась до timeout`  
   Функція повертає результат, а таймер очищається.

2. `операція перевищила ліміт часу`  
   Запускається таймер, і після досягнення `timeoutMs` проміс реджектиться помилкою `Operation timed out`.

3. `операція завершилась помилкою`  
   Помилка передається назовні без втрати контексту.

4. `операція завершилась вчасно, але таймер був очищений`  
   Успішний результат повертається без зайвого тайм-ауту.

## Приклад

```typescript
const timeouter = new Timeouter({
    timeoutMs: 2000
});

const result = await timeouter.withTimeout(async () => {
    await new Promise(resolve => setTimeout(resolve, 1000));
    return "Success";
});

console.log(result);
```

У цьому прикладі операція виконується за 1 секунду, що менше за ліміт 2 секунди. Тому проміс успішно резолвиться.

1. Завантажте репозиторій та перейдіть у папку проєкту:

```bash
npm install
```

npm run dev
