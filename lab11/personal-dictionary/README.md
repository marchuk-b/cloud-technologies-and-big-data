# Docker: Написати Docker Compose файл для двох сервісів

Навчальний проєкт для створення простого особистого словника з використанням Node.js, Express та Redis.

## Мета

- ознайомитися з базовою архітектурою веб-додатку;
- зберігати слова та визначення у Redis;
- запустити додаток у Docker Compose;
- перевірити роботу API та інтерфейсу;
- зрозуміти принципи роботи контейнеризованого застосунку.

## Що таке цей проєкт

Це невеликий веб-додаток, у якому користувач може:
- додати нове слово;
- зберегти його визначення;
- переглянути всі збережені терміни.

Вся логіка реалізована через сервер на Express, а дані зберігаються у Redis. Додаток запускається як два Docker-контейнери:
- `app` — веб-сервер Node.js;
- `redis` — база даних для зберігання словника.

## Як працює реалізація

У проєкті використовується Docker Compose для запуску декількох сервісів одночасно.

Файл `docker-compose.yaml` визначає два сервіси:

```yaml
services:
  app:
    build: ./app
    ports:
      - "8080:8080"
    depends_on:
      - redis

  redis:
    image: redis:alpine
```

Сервер `app` працює на порті `8080` і взаємодіє з Redis за адресою `redis://redis:6379`.

Основні API-ендпоінти:

- `POST /words` — додати слово та визначення;
- `GET /words` — отримати всі слова зі словника.

Також у папці `app/public` міститься простий інтерфейс HTML, який дозволяє користувачу вводити нові слова через форму.

## Підготовка

1. Переконайтеся, що Docker та Docker Compose встановлені та працюють.
2. Перейдіть у папку проєкту:

```bash
cd lab11/personal-dictionary
```

3. Перевірте вміст каталогу:

```bash
ls
```

## Запуск demo

Для запуску застосунку використовується команда:

```bash
docker compose up --build
```

Після запуску проєкт буде доступний за адресою:

```text
http://localhost:8080
```

## Перевірка роботи

### 1. Перегляд запущених сервісів

```bash
docker compose ps
```

### 2. Перевірка HTTP-відповіді

```bash
curl http://localhost:8080
```

### 3. Перевірка API для додавання слова

```bash
curl -X POST http://localhost:8080/words \
  -H "Content-Type: application/json" \
  -d '{"word":"Docker","definition":"Platform for containerization"}'
```

### 4. Отримання всіх слів

```bash
curl http://localhost:8080/words
```

## Зупинка та очищення

Щоб зупинити контейнери:

```bash
docker compose down
```

Ця команда зупиняє сервіси і видаляє створені мережі для цього проєкту.

## Короткий набір команд

```bash
docker compose up --build
docker compose ps
curl http://localhost:8080
docker compose down
```

## Результат

Після запуску проєкту відкритий браузер за адресою `http://localhost:8080` дозволяє:
- додавати слова до словника;
- зберігати визначення в Redis;
- бачити список всіх записів на сторінці.

Це демонструє базову роботу веб-додатку з Docker Compose та зовнішньою in-memory базою даних Redis.
