# Throttle Lab

Навчальний проєкт для дослідження патерна **Throttle**.

## Мета

- зрозуміти принцип роботи throttle;
- обмежити кількість викликів функції за часовий інтервал;
- дослідити режими `leading` і `trailing`;
- реалізувати чергу відкладених викликів;
- протестувати власну throttle-обгортку.

## Що таке throttle

Throttle — це патерн, який обмежує кількість виконань функції протягом заданого часового інтервалу.

Це корисно для:

- обробки руху миші;
- прокручування сторінки;
- зміни розміру вікна;
- введення з клавіатури;
- обмеження API-запитів.

## Як працює реалізація

У цьому проєкті throttle реалізовано у класі `Throttler` у файлі `src/throttler.ts`.

Параметри:

- `maxCallsNumber` — максимальна кількість викликів за один інтервал;
- `delay` — тривалість інтервалу в мілісекундах;
- `leading` — чи виконувати доступні виклики одразу;
- `trailing` — чи додавати надлишкові виклики до черги.

Виклики, які перевищують ліміт, зберігаються в черзі та виконуються під час наступних інтервалів.

### Основні сценарії

1. `leading: true`, `trailing: false`  
   Дозволені виклики виконуються одразу, а надлишкові ігноруються.

2. `leading: false`, `trailing: true`  
   Виклики додаються до черги та виконуються після завершення поточного інтервалу.

3. `leading: true`, `trailing: true`  
   Доступні виклики виконуються одразу, а решта додаються до черги.

4. `leading: false`, `trailing: false`  
   Виклики, які не можуть бути виконані одразу, ігноруються.

## Приклад

```typescript
const throttler = new Throttler({
    rate: {
        maxCallsNumber: 2,
        delay: 1000
    },
    leading: true,
    trailing: true
});

const throttledFunction = throttler.throttle((message: string) => {
    console.log(message);
});

throttledFunction("Виклик 1");
throttledFunction("Виклик 2");
throttledFunction("Виклик 3");
```

У цьому прикладі максимум два виклики виконуються протягом одного інтервалу в одну секунду. Надлишкові виклики потрапляють до черги.

## Підготовка

1. Завантажте репозиторій та перейдіть у папку проєкту:

```bash
cd lab4/throttle-lab
```

2. Встановіть залежності:

```bash
npm install
```

## Запуск demo

Для запуску демонстраційного прикладу використовуйте:

```bash
npm run dev
```

Демонстраційний приклад знаходиться у файлі `src/index.ts`.
