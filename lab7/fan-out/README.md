# Fan-Out Lab

Навчальний проєкт для дослідження патерна **Fan-Out (демультиплексор)**.

## Мета

- зрозуміти принцип роботи fan-out;
- розподілити одну чергу задач між декількома воркерами;
- збільшити паралелізм для повільних асинхронних обчислень;
- реалізувати чергу задач та агрегатор результатів;
- перевірити коректне завершення після відсутності задач.

## Що таке fan-out

Fan-Out — це патерн, за допомогою якого один потік задач розподіляється між кількома виконавцями (worker-ами), що працюють паралельно.

Це корисно для:

- обробки великої кількості задач;
- паралельного виконання незалежних обчислень;
- розвантаження одного джерела подій або черги;
- збільшення пропускної здатності сервісів;
- запобігання перевантаженню одного виконавця.

## Як працює реалізація

У цьому проєкті fan-out реалізовано у функції `fanOut(process, workers)` у файлі `src/fan-in.ts`.

Параметри:

- `process` — функція, яка приймає задачу і повертає результат;
- `workers` — кількість паралельних воркерів, які одночасно обробляють задачі.

Інтерфейс:

```typescript
fanOut(process: (Task) => Result, workers: N) -> { submit(task), results(), close() }
```

Функція:

- приймає нові задачі через `submit(task)`;
- розподіляє їх між доступними воркерами;
- збирає результати через `results()`;
- коректно завершує роботу після `close()` або `shutdown()`;
- не обробляє одну і ту ж задачу двічі;
- підтримує graceful shutdown без зависання.

### Основні сценарії

1. `задачі надходять швидше, ніж обробляються одним воркером`  
   Кілька воркерів беруть задачі паралельно, тому загальний час зменшується.

2. `одна задача не дублюється`  
   Кожна задача береться в роботу лише одним воркером.

3. `немає більше задач`  
   Після виклику `close()` воркери завершують роботу, а результати видаються до кінця.

4. `після завершення всі активні воркери зупиняються без втрати результатів`  
   Реалізація використовує graceful shutdown.

## Приклад

```typescript
const queue = fanOut(async (task: number) => {
  await new Promise((resolve) => setTimeout(resolve, 80));
  return task * 2;
}, 3);

for (const value of [1, 2, 3, 4, 5, 6]) {
  queue.submit(value);
}

await queue.close();

for await (const result of queue.results()) {
  console.log(result);
}
```

У цьому прикладі шість задач обробляються трьома воркерами одночасно, тому час виконання менший, ніж у випадку з одним воркером.
