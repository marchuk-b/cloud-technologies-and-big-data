# Docker: запуск першого контейнера

Навчальний проєкт для ознайомлення з базовим робочим процесом Docker.

## Мета

- встановити середовище виконання контейнерів;
- завантажити готовий образ з Docker Hub;
- запустити контейнер із мапінгом портів;
- перевірити роботу застосунку через HTTP;
- переглянути логи та зупинити контейнер;
- зрозуміти різницю між `docker stop` та `docker rm`.

## Що таке Docker

Docker — це платформа для запуску програм у ізольованих контейнерах. Контейнери використовують загальний ядро ОС, але мають власне середовище виконання і залежності. Це дозволяє запускати один і той самий додаток однаково на різних машинах без конфліктів між інсталяціями.

У цьому завданні використовується готовий образ `containous/whoami`, який віддає інформацію про запит і показує, що контейнер працює як веб-сервіс.

## Як працює реалізація

У лабораторній роботі використовується базовий сценарій:

1. Завантажується готовий образ з реєстру Docker Hub.
2. Запускається контейнер з іменем `whoami-lab`.
3. Порт 8080 хоста прокидається до порту 80 контейнера.
4. Додаток перевіряється через HTTP-запит до `http://localhost:8080`.
5. Контейнер можна переглянути в логах, зупинити або видалити.

Формат запуску:

```bash
docker run -d --name whoami-lab -p 8080:80 containous/whoami
```

Параметри:

- `-d` — запустити контейнер у фоновому режимі;
- `--name whoami-lab` — призначити контейнеру назву;
- `-p 8080:80` — прокинути порт 8080 на хості до порту 80 у контейнері;
- `containous/whoami` — образ, який буде запущено.

## Підготовка

1. Переконайтеся, що Docker або Rancher Desktop встановлено та запущено.
2. Перевірте роботу Docker:

```bash
docker --version
docker ps
docker ps -a
```

3. Завантажте образ:

```bash
docker pull containous/whoami
```

## Запуск demo

Для запуску контейнера використовується команда:

```bash
docker run -d --name whoami-lab -p 8080:80 containous/whoami
```

Після запуску перевірте статус контейнера:

```bash
docker container ls
```

## Перевірка роботи

### 1. Перегляд запущених контейнерів

```bash
docker container ls
```

### 2. Перевірка всіх контейнерів

```bash
docker container ls -a
```

### 3. Перевірка HTTP-відповіді

```bash
curl http://localhost:8080
```

### 4. Перегляд логів

```bash
docker logs whoami-lab
```

### 5. Зупинка контейнера

```bash
docker stop whoami-lab
```

### 6. Видалення контейнера

```bash
docker rm whoami-lab
```

> `docker stop` лише зупиняє контейнер. `docker rm` видаляє його повністю з системи Docker.

## Короткий набір команд

```bash
docker pull containous/whoami
docker run -d --name whoami-lab -p 8080:80 containous/whoami
docker container ls
docker logs whoami-lab
curl http://localhost:8080
docker stop whoami-lab
docker rm whoami-lab
```

## Результат

Після успішного запуску контейнер повинен відповідати на запити за адресою:

```text
http://localhost:8080
```

У відповідь сервер має повернути інформацію про запит, що підтверджує коректну роботу контейнера.
